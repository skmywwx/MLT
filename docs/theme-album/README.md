# 主题相册

像手机图库一样管理本地上传的照片，按旅行等主题整理成文件夹，还能一键切换成明信片收纳册浏览；在此基础上，用手账式编辑器制作属于你的电子相册。

> 当前为 **Web 网页端原型**，适合在浏览器中体验核心功能。照片保存在本机，暂不支持云同步、微信使用、导出分享与实体打印。

---

## 快速开始

1. 用电脑浏览器打开 [`index.html`](index.html)（或访问演示地址）。
2. 注册 / 登录账号（原型阶段可能为简化登录）。
3. 点击顶部 **上传照片**，从本机选择图片。
4. 从左侧进入 **图库** 或 **电子相册**，开始整理与创作。

---

## 用户指南

### 这个平台能做什么？

| 能力 | 一句话说明 |
|------|------------|
| **照片收纳** | 上传的照片先进入「全部照片」，再按主题归入文件夹 |
| **明信片浏览** | 同一批照片可切换成明信片册，像翻实体明信片一样回顾旅程 |
| **电子相册** | 像做手账一样排版照片、加文字和贴纸，随时预览翻页效果 |
| **个人中心** | 管理头像、昵称，查看全部照片、文件夹和电子相册作品 |

---

### 1. 上传与管理照片

**上传**

- 点击页面顶部的 **上传照片**，从电脑里选择图片。
- 每张照片会自动记录 **导入时间**；若照片带有拍摄信息，还会读取 **拍摄日期、时间、地点**。

**全部照片**

- 所有刚上传的照片都会进入 **全部照片**，就像手机相册里的「所有照片」。
- 可以按网格或列表方式浏览，并用搜索框快速查找。

**小提示**

- 照片目前只保存在 **本机浏览器**，换电脑或清空浏览器数据后可能无法找回，请及时备份重要照片。
- 暂不支持从云端导入或自动同步手机相册。

---

### 2. 建立主题文件夹

适合把一次旅行、一个活动或一个主题的照片归在一起。

1. 进入 **图库 → 全部照片**。
2. **多选** 要整理的照片。
3. 创建主题文件夹，例如「2025 京都之旅」。
4. 在 **主题文件夹** 列表中打开文件夹，查看该主题下的所有照片。

同一张照片可以被加入多个主题文件夹，不会重复占用存储空间。

---

### 3. 文件夹模式 ↔ 明信片收纳册

进入某个主题文件夹后，可以在两种浏览方式之间 **一键切换**，照片内容不变，只是展示形式不同。

**文件夹模式**

- 以网格或列表查看照片，方便管理和挑选。
- 适合快速浏览、批量操作。

**明信片收纳册模式**

- 每页展示 **2 张横版明信片**。
- 照片上方显示：**拍摄日期 → 拍摄时间 → 拍摄地点**。
- 照片下方显示：**导入日期**（如 2025-08-14）。
- 点击左右按钮翻页，也可用键盘 **← →** 方向键翻页。

如果照片没有拍摄信息，会显示「未知日期 / 时间 / 地点」，不影响浏览。

---

### 4. 制作电子相册

在整理好照片后，可以创建一本 **手账风格** 的电子相册。

**创建与编辑**

1. 从左侧进入 **电子相册**，新建一本相册。
2. 在画布上自由排版：拖拽、缩放、旋转照片。
3. 可裁剪图片、添加文字、使用贴纸和插画素材装点页面。
4. 支持新增、删除、复制和排序内页，适合碎片时间慢慢完成。
5. 编辑过程会 **自动保存草稿**，避免意外丢失。

**常用编辑能力**

| 功能 | 说明 |
|------|------|
| 调整图片 | 自由拉伸、缩放，可裁剪局部画面 |
| 智能消除 | 圈选路人或杂物，让画面更干净（效果因照片而异） |
| 文字 | 添加标题、说明、心情记录，可调整字体、大小、颜色等 |
| 素材 | 使用平台内置贴纸、插画装饰内页 |
| 页面管理 | 随时新增或调整页面顺序 |

**预览成品效果**

- 编辑时随时点击 **【预览】**。
- 进入拟真翻页界面，模拟实体相册的浏览体验。
- 预览基于当前最新内容，退出后可继续编辑。

---

### 5. 账号与个人中心

- 使用手机号或邮箱 **注册 / 登录**。
- 在 **个人中心** 修改头像、昵称等基本信息。
- 在 **我的作品** 中查看：
  - 全部照片
  - 我的主题文件夹
  - 我的电子相册

```text
上传照片 → 全部照片浏览 → 多选建立主题文件夹
    → 文件夹模式整理 / 明信片册回顾
    → 新建电子相册 → 手账式编辑 → 【预览】翻页查看
```

## 常见问题

**Q：照片存在哪里？**  
A：目前存在本机浏览器中，不上传云端。换设备后需要重新上传。

**Q：能在手机上用吗？**  
A：本期以电脑浏览器为主。微信小程序计划在后续版本推出。

**Q：可以分享给朋友或打印成实体相册吗？**  
A：暂不支持。导出分享和实体打印为后续规划功能。

**Q：明信片册里为什么有些信息是「未知」？**  
A：说明该照片缺少拍摄时间或地点信息，属于正常情况。

**Q：编辑到一半可以下次继续吗？**  
A：可以。电子相册会自动保存草稿，下次登录后继续编辑。

## 适合谁使用？

- **旅行归来**：想把照片按旅程整理，并用明信片方式回顾。
- **喜欢手账 / Zine 风格的年轻人**：希望作品有设计感、能自由排版。
- **希望操作简单的用户**：用文件夹归类，选模板、拖拽即可完成一本相册。
