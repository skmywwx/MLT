# MLT · 模力通原型

单文件 HTML 原型（`index.html`）：桌面启动 → 登录 → 首页输入 → **对话页**自动播放 AI 智能体任务流。

## 测试步骤

1. **双击打开** `index.html`
2. 桌面 → 登录（任意账号）→ **办公写作Agent**
3. 输入需求并发送，或点快捷 pill：
   - **写作**：`请生成一份中式，大约预算5W左右的婚礼策划方案`（对话页 + docx 预览）
   - **深度研究**：交互模式完整多智能体流程
   - **AI PPT**：交付 `.pptx` 文件
4. 自动进入**对话页**：顶部进度条 + 可滚动消息流 + 底部输入框
5. 点击 **新建对话** 或侧边栏 **办公写作Agent** 返回首页

## 对话页内容（对齐 PRD §7）

- 用户消息气泡（右上）
- 模式推荐 → 负责人交接（统筹 → 检索 → 写作 → 编辑）
- 内嵌 **待办事项** 面板（随进度更新）
- 工具日志、检索结果、大纲确认
- 三审三校 → **文档预览**（图2）→ 文件交付（docx / pptx）
- 流程可视化、评价、「你可能想问」

超长内容可在中间区域**上下滚动**浏览。
