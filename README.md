# MLT · 模力通原型

模力通办公写作 Agent **单文件 HTML 原型**（`index.html`）与 PRD 文档。

## 原型测试（完整流程）

所有交互逻辑（含 AI 智能助手任务流模拟）均内嵌在 **`index.html`** 中，无需额外 JS 文件。

### 步骤

1. **双击打开** `index.html`（或拖入 Chrome / Edge）
2. 桌面点击 **模力通** → 登录（任意用户名和密码）
3. 左侧 **办公写作Agent** → 输入需求，或点绿色 **「写作」** 自动填充示例
4. 展开 **快速模式**，选择 **交互模式**（含「整合/报告」等词会自动切换）
5. 点击 **发送 ↑** 或按 **Enter**
6. 页面进入 **智能体工作区**，自动播放：任务拆解 → 资料检索 → 大纲 → 分章撰写 → 三审三校 → 交付
7. **返回首页** 或再点侧边栏 **办公写作Agent** 可重新测试

### 可选 URL 参数（开发调试）

```
index.html?skipLogin=1&autoDemo=interactive
```

跳过桌面/登录并自动播放交互模式完整流程。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 完整原型（桌面 → 登录 → 首页 → 智能体工作区） |
| `PRD.md` | 产品需求文档 |
| `PRD.html` | PRD 双栏阅读页 |
| `scripts/sync-prd-html.py` | PRD 同步脚本 |

## 模式说明

- **交互模式**：6 步待办 + 多智能体协作 + 进度条（对齐 PRD 深度研究任务流）
- **快速模式**：精简路径，直接生成 docx
