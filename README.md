# MLT · 模力通原型

模力通办公写作 Agent HTML 原型与 PRD 文档。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 办公写作 Agent 交互原型（桌面启动 → 登录 → 首页 → 任务沙盒） |
| `scripts/workflow-sim.js` | **任务处理沙盒**模拟引擎（前端纯静态，无真实后端） |
| `PRD.md` | 产品需求文档（编辑源） |
| `PRD.html` | PRD 双栏阅读页 |

## 如何测试「智能助手任务处理沙盒」

沙盒指：发送需求后，由 `scripts/workflow-sim.js` 在前端按 PRD 任务流**逐步模拟**多智能体协作、进度条、待办、工具日志与文档交付，**不调用真实 AI 接口**。

### 方式一：完整路径（推荐首次体验）

1. 用本地静态服务打开（避免部分浏览器对 `file://` 限制脚本）：

```bash
cd /path/to/MLT
python3 -m http.server 8080
```

浏览器访问：`http://localhost:8080/index.html`

2. 点击桌面 **模力通** 图标 → 登录（任意用户名/密码）→ 进入主界面。
3. 左侧侧边栏确认选中 **办公写作Agent**（默认已选中）。
4. 在输入框输入需求，或点击 **「沙盒演示」** / 绿色 **「写作」** pill 自动填充 demo 文案。
5. 建议展开 **快速模式** 下拉，选择 **交互模式**（含「整合/分析/报告」等词时会自动切换）。
6. 点击发送 ↑ 或按 **Enter**。
7. 页面切换到 **智能体工作区**：顶部进度条、右侧待办、中间消息流自动播放全流程。
8. 点击 **返回首页** 或侧边栏 **办公写作Agent** 可回到输入页再次测试。

### 方式二：URL 直达沙盒（适合反复测试）

跳过桌面/登录并自动启动演示：

```
http://localhost:8080/index.html?skipLogin=1&autoDemo=interactive
```

快速模式精简沙盒：

```
http://localhost:8080/index.html?skipLogin=1&autoDemo=quick
```

### 方式三：浏览器控制台手动触发

登录并进入首页后，在 DevTools Console 执行：

```javascript
// 交互模式完整沙盒
MLTWorkflowSandbox.start("请将以上文档内容整合，并基于我上传的文件生成一份工作总结分析报告", "交互模式");

// 快速模式精简沙盒
MLTWorkflowSandbox.start("帮我写一份简短工作通知", "快速模式");

// 停止并返回首页
MLTWorkflowSandbox.stop();
```

### 方式四：最近对话回放

发送过一次需求后，点击左侧 **最近对话** 列表中的条目，会用该文案重新进入沙盒。

## 沙盒模拟范围（对齐 PRD）

| 阶段 | 沙盒表现 |
| --- | --- |
| 需求理解 | 用户消息、附件 chips、模式推荐 |
| 任务规划 | 统筹专家、6 步待办、进度百分比 |
| 资料检索 | 检索专家、工具日志、来源卡片 |
| 内容撰写 | 大纲确认、分章文件、docx 合并 |
| 质量校验 | 三审三校状态与修正统计 |
| 最终交付 | 结果文件、流程可视化、评价、「你可能想问」、文件打包弹窗 |

## 模式差异

- **交互模式**：完整 6 步待办 + 多智能体消息 + 大纲确认 + 三审三校（约 30–40 秒自动播完）。
- **快速模式**：单进度条 + 直接生成 docx，无右侧待办面板。

## 修改原型后
